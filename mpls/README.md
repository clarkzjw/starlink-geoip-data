# Starlink MPLS Label to PoP Mapping

The [mpls-label-to-pop.csv](./mpls-label-to-pop.csv) file contains the SR-MPLS label-to-PoP mappings we have identified in Starlink's global backbone network.

The mapping may not be exhaustive and may change as Starlink's network evolves.

For details on our methodology and how this mapping is used, please refer to our accepted ACM IMC'26 paper, Measuring Starlink Aviation Around the World (PDF link to be updated in early September, 2026).
